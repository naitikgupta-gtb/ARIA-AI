How it runs

Three steps, no account required.

ARIA doesn't route your requests through a server — it calls Google's Gemini API directly, using a key that's yours alone.

1

Download & open

One .exe, no installer. Windows will flag it as unrecognized the first time — that's expected for a new indie app, see below.

2

Paste your API key

ARIA asks for a free Gemini key on first launch, with a direct link to get one. It's stored in Windows Credential Manager, not in a plain file.

3

Talk to it

Click engage and start talking — or typing. Every tool call shows up live in the activity log so you can see exactly what it's doing.

Get ARIA

Download and run it in under a minute.

ARIA is free and open-source. Your data — memory, clipboard history, files — stays on your machine; nothing is sent anywhere except your own direct calls to Gemini.

About the Windows warning

You'll likely see "Windows protected your PC" on first run. This appears for any new app that isn't code-signed yet — it isn't a sign anything's wrong. Click More info → Run anyway. Source is public on GitHub if you'd like to check it yourself first.
